# ☕️ CupScout-Backend

### 👥 참여자  
**도지현**, **조수민**

<br/>

> **CupScout**는 음료를 마시는 ‘Cup’과 탐험가를 뜻하는 ‘Scout’의 합성어로,  
> **사용자의 다양한 니즈에 맞는 특별한 카페를 추천해주는 플랫폼**입니다.
>
> - ‘책 읽기 좋은 카페’, ‘빙수 맛집’ 등 사용자 선호에 맞춘 카페 탐색 지원  
> - 다양한 테마와 위치 기반 필터링을 통해 탐험하듯 카페를 찾아가는 경험 제공  

<br/>
